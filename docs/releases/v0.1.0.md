# XMind MD 0.1.0 — Alpha

**Primera publicación pública, pre-1.0. No es una declaración de estabilidad de API ni de compatibilidad completa con XMind.**

XMind MD transforma un subconjunto documentado de Markdown enriquecido en un modelo intermedio neutral IR 1.0.0 y puede exportarlo a JSON o a libros XMind modernos.

## Incluye

- Parser Markdown enriquecido con front matter YAML y directivas XMind.
- Modelo IR 1.0.0, JSON Schema, serialización y validación semántica.
- Resolución de estilos mediante catálogos YAML embebidos y externos.
- Adaptadores JSON y XMind.
- CLI `xmind-md`.
- Ejemplos y documentación técnica.
- Licencia MIT y avisos de procedencia de terceros.

## Validación automatizada

La CI de la versión candidata ejecuta 161 pruebas por versión en Python 3.10, 3.11 y 3.12, Ruff lint/format, generación de libros smoke, construcción y verificación de wheel/sdist e instalación limpia de ambas distribuciones con conversiones CLI JSON/XMind.

## Limitaciones conocidas

- El parser no implementa CommonMark/GFM completo.
- El perfil XMind no exporta recursos/imágenes, tareas, boundaries, summaries, extensiones ni temas `summary`.
- Los bloques de contenido se aplanan a notas y se pierde parte de la estructura/formato inline.
- CI valida Ubuntu, no Windows.
- Python 3.10 está fuera de soporte upstream desde el 1 de octubre de 2026.
- El inventario de dependencias no constituye un SBOM completo de transitivas.
