# XMind de estudio y referencia

Esta carpeta está destinada a reunir mapas `.xmind` aportados como ejemplos de estudio para analizar las convenciones reales que queremos incorporar a **PMD (Pableras Markdown)**.

El objetivo inicial es estudiar especialmente dos ámbitos:

- **Legislación:** jerarquía normativa, libros, títulos, capítulos, secciones, artículos, apartados, disposiciones, referencias y convenciones visuales.
- **Tablas en general:** organización de filas y columnas, encabezados, agrupaciones, celdas destacadas, leyendas, relaciones entre tablas y formas de representar información tabular dentro de un mapa.

También podremos incluir mapas mixtos cuando combinen estructuras jurídicas, esquemas y tablas.

## Cómo añadir un mapa

1. Abre esta carpeta en GitHub.
2. Selecciona **Add file → Upload files**.
3. Arrastra el archivo `.xmind` y confirma el commit.
4. Utiliza un nombre descriptivo y evita sobrescribir el original.

Convención de nombres sugerida:

`ámbito-tema-descripción-versión.xmind`

Ejemplos:

- `legislacion-constitucion-esquema-general-01.xmind`
- `legislacion-ley-articulos-y-disposiciones-01.xmind`
- `tablas-comparativa-organismos-01.xmind`

## Información complementaria (opcional)

Junto al mapa puedes añadir un archivo Markdown con el mismo nombre base. Por ejemplo, `legislacion-constitucion-esquema-general-01.md`.

Puedes indicar:

- Qué representa el mapa y qué parte te interesa estudiar.
- Qué colores, formas o formatos tienen un significado especial.
- Qué elementos consideras imprescindibles conservar al convertirlo.
- Si contiene tablas, qué convenciones de filas, columnas, encabezados o celdas debemos observar.

No hace falta que documentes todo: el análisis del archivo será el punto de partida.

## Criterios de conservación

- Trataremos los archivos originales como **fuentes de referencia**: no los modificaremos para experimentar.
- Los análisis, propuestas de etiquetas PMD y estilos derivados se documentarán por separado.
- No daremos por definitiva una convención visual o semántica hasta contrastarla con varios ejemplos y validarla contigo.
- La conversión deberá aspirar a conservar la estructura y los datos de origen necesarios para reconstruir el mapa.

## Importante: repositorio público

Este repositorio es público. Sube únicamente mapas que puedas compartir públicamente y que no contengan datos personales, información confidencial, anotaciones privadas ni materiales de terceros cuya publicación no esté autorizada. Si un mapa no se puede publicar, no lo subas aquí: podremos estudiar una copia anonimizada o trabajar con el archivo adjunto en la conversación.
